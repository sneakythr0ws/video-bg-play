# LSP / IDE / Lint Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ESLint, Prettier, `web-ext lint`, IDE settings, and OpenCode integration to the video-bg-play Firefox extension project.

**Architecture:** Introduce a minimal npm-based dev tooling layer alongside the existing Makefile-based packaging. ESLint and Prettier enforce JS/JSON style; `web-ext lint` validates the WebExtension package; OpenCode configuration exposes the same commands the human developer uses.

**Tech Stack:** npm, ESLint, Prettier, web-ext, GNU Make, IntelliJ IDEA/WebStorm project settings.

## Global Constraints

- Keep the project simple: no TypeScript, no bundler, no CI pipeline for now.
- Do not migrate to Manifest V3.
- Content script remains a non-module script (`sourceType: script`).
- `make check` must exit 0 after the migration.
- `web-ext lint` Manifest V2 deprecation warnings are expected and acceptable.
